# Thematic Stocks

This project provides stock recommendations based on real-world **investment themes** sourced from [Charles Schwab's Thematic Investing](https://www.schwab.com/thematic-investing/themes). It includes a fast React frontend and Python backend that scrapes theme information and generates investment recommendations using AI.

### Frontend
- **React**: A JavaScript library for building user interfaces.
- **Vite**: A modern frontend build tool for fast development.

### Backend
- **Flask (Python)**: For handling backend operations.

## Getting Started

### Prerequisites
- Node.js and npm installed for the frontend.
- Python and pip for backend development.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/TannerM99/thematic-stocks.git
   ```
2. Navigate to the `frontend` directory and install dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. [Add backend setup instructions if applicable.]

### Usage

